# DWMY

**Discussion Without Missing Yesterday**

DWMY is an open-source discussion platform built around structured, persistent conversations.

Rather than treating every discussion as a single continuous feed, DWMY organizes conversations around defined subjects, communities, markets, and time periods so that information remains easier to navigate and revisit.

DWMY is developed by **FRCTAL**.

## Open Source

DWMY is open source.

The source code for the application is publicly available in this repository and can be inspected, studied, modified, and contributed to in accordance with the project's license.

DWMY itself may offer paid services, subscriptions, hosted infrastructure, premium capabilities, and other commercial features.

Open-source software and a paid hosted service are not mutually exclusive. The source code can remain open while FRCTAL operates DWMY as a commercial platform.

## Current Status

DWMY is currently under active development.

The platform currently includes functionality for:

- Structured market discussions
- Day, week, month, and year discussion segmentation
- Live chat
- Conversations
- Communities
- Direct messaging
- User profiles and ranks
- Role and capability-based access

Additional functionality is actively being developed.

## Technology

DWMY is currently built with:

- React
- Vite
- Supabase
- PostgreSQL

## Access

DWMY is designed around multiple levels of access.

Some areas of the platform are available for free, while additional capabilities may be available through beta access, trials, subscriptions, or other access programs.

The hosted DWMY service may therefore differ from what is available simply by running the open-source code.

## Development

DWMY is evolving rapidly. APIs, database structures, interfaces, and application behavior may change while the project remains under active development.

Documentation for local development, contribution guidelines, deployment, and architecture will be expanded as the project matures.
